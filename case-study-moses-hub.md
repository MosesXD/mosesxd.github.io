# Building Moses' Hub

*A personal website, portfolio, and development playground.*

## Overview

Moses' Hub is my personal website and an ongoing web-development project. I created it as a place to bring together my projects, experiments, interests, and development progress.

What began as a personal website gradually grew into a multi-page experience with a portfolio, gaming library, updates, themes, and interactive features.

- **Project:** Moses' Hub
- **Type:** Personal website and portfolio
- **Status:** Live and continuously evolving
- **Technologies:** HTML, CSS, JavaScript
- **Hosting:** GitHub Pages
- **Website:** https://mosesxd.github.io/
- **Repository:** https://github.com/MosesXD/mosesxd.github.io

## The idea

I wanted a website that was more than a basic introduction page. I wanted somewhere I could share what I was building, organize my projects, experiment with different ideas, and gradually improve my development skills.

The site became a place where I could learn through practical work instead of only following tutorials.

## How it developed

The website grew from a simple page into a multi-page hub. Its sections now cover Home, Projects, Games, Updates, About, Links, Services, Partners, Support, Lab, and other experiments.

The site has also gained theme customization, responsive layouts, motion effects, project-status labels, visitor analytics, and integrations that rely on external services.

## Technical approach

The main site uses HTML for structure, CSS for layout and visual styling, and JavaScript for interactive behaviour such as navigation, theme preferences, and other site features.

Git and GitHub help manage the code and track changes. GitHub Pages hosts the static website.

Some integrations, such as Last.fm Now Playing, require a separate server-side endpoint because a static GitHub Pages site cannot run server-side functions. The interface and endpoint code exist, but the live provider configuration still needs verification.

## Challenges and lessons

- Keeping the design and navigation consistent across a growing multi-page website.
- Making the site work across different screen sizes.
- Improving accessibility and keyboard navigation.
- Connecting external services without exposing private credentials.
- Keeping project descriptions, statuses, and repository links accurate.
- Organizing changes across branches and reviewing updates before merging.

These challenges helped me understand that building a website involves more than making a page look good. It also requires testing, maintenance, documentation, security awareness, and clear project organization.

## What's next

Moses' Hub is still evolving. Priorities include accessibility improvements, device testing, verifying optional integrations, and documenting the development journey.

Real screenshots and a demo video may be added later, once I have captures I'm happy to share. They are not required for the current portfolio.

## Reflection

Moses' Hub represents my learning process as a developer. It gives me a place to experiment, make mistakes, solve problems, and turn ideas into working projects.

The goal is not to pretend that everything is finished. It is to keep building, document what changes, and show how the work improves over time.
