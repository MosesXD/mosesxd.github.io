CASE STUDY / 01

Building Moses' Hub.

A personal website, portfolio, and development playground that grew alongside my web-development skills.

PROJECTMoses' Hub
TYPEPersonal website / portfolio
STATUSLive and evolving
STACKHTML · CSS · JavaScript

01 — The idea

I wanted a place that was more than a basic introduction page. I wanted somewhere to share what I was building, organize my projects, experiment with new ideas, and document my progress as I learned web development.

That idea became Moses' Hub: part personal space, part portfolio, and part development playground.

02 — How it grew

The site developed from a simple page into a multi-page experience. It now brings together a home page, project showcase, gaming library, development updates, personal information, services, partners, support options, and a lab for experiments.

As the site grew, I worked on keeping navigation, styling, themes, and shared components consistent across the pages.

03 — Technical approach

The main website uses HTML for structure, CSS for layout and styling, and JavaScript for navigation, themes, and interactive behaviour. Git and GitHub are used to manage the code and track changes, while GitHub Pages hosts the static site.

Some features, such as the Last.fm integration, need a separate server-side endpoint because GitHub Pages cannot execute server-side functions. The code and interface exist, but the live provider configuration still needs verification.

04 — Challenges and lessons

  • Keeping the design and navigation consistent as more pages were added.
  • Improving the experience across phone, desktop, and different screen sizes.
  • Learning to account for accessibility, keyboard navigation, and reduced-motion preferences.
  • Connecting external services without exposing private credentials in browser code.
  • Keeping project descriptions, repository links, and release notes accurate as work changed.
  • Using branches and pull requests to review changes before they reach the main site.

05 — What's next

Moses' Hub is still evolving. The next priorities are improving accessibility, testing the site across devices, verifying optional integrations, and continuing to document the projects as they develop.

Real screenshots and a demo video may be added later, when I have captures I'm happy to share. They are not required for the site to be useful today.

06 — Reflection

Moses' Hub represents my learning process as a developer. It gives me a place to experiment, solve problems, make mistakes, and turn ideas into working projects.

The goal is not to pretend everything is finished. It is to keep building, document what changes, and show how the work improves over time.
